# bom-history 스킬 (BOM 변경 이력)

명령 하나로 끝난다 (지난 비교 기록 모으기·합치기를 도구가 함). 결과 처리는 전역 지침 4장, 승인은 5장을 따른다.
두 판을 새로 비교하는 일은 이 스킬이 아니라 mbom-diff다. 이 스킬은 이미 한 비교만 모은다.

## 명령
PowerShell에서는 명령 앞에 전역 지침의 인코딩 줄을 붙인다. `<...>`만 바꾼다. 1번만 실행한다.

`python "C:\AIKIT\bom-kit\bom.py" history --file "<그 BOM의 아무 판.xlsx>"`

- 판 하나만 주면 된다. 그 판과 비교로 이어진 다른 판(옛 판·새 판)의 기록을 도구가 따라가 모은다.
- 다른 명령(pandas-kit, bom.py diff 등)을 섞지 않는다. 기록 파일을 직접 읽지 않는다.

## 도구가 모으는 기준 (사용자가 물으면 알린다)
1. 기록은 mbom-diff를 실행할 때마다 옛 판 옆 결과 폴더(`<옛 판 이름>_bom`)에 하나씩 남는다. 비교한 적이 없으면 이력도 없다.
2. 파일이 바뀌지 않은 채 같은 두 판을 여러 번 비교했으면 마지막 비교만 센다.
3. 비교한 뒤 원본이 바뀌었거나 없어졌으면 `warnings`로 알린다 (기록은 그때의 비교다).

## 결과 알리기
- `preview`를 그대로 알린다 (첫 줄은 비교 건수와 판 수, 줄마다 `[비교] <시각> <옛 판> -> <새 판>: <그때의 변경 건수>`, 끝 줄은 변경 이력 파일).
  줄을 직접 세거나 고쳐 쓰지 않는다.
- 0건이면 "비교 기록이 없습니다"를 그대로 알리고 다시 실행하지 않는다. 두 판을 비교할지 사용자에게 묻는다 (mbom-diff).
- `warnings`가 있으면 그대로 알린다.
- 이력을 엑셀로 보고 싶다고 하면 `output_file`(변경이력 .csv)을 excel-kit으로 연다.
