# pandas-kit 설계 (남은 결정)

2026-11-13 초안의 내용은 첫 판(0.1.0)으로 구현해 `README.md`(사람용 상세)·`SKILL.md`(에이전트용)·`CHANGELOG.md`로 옮겼다.
원칙급 결정은 `docs/DECISIONS.md` 2026-11-13 두 줄(완결형 작업 도구, 상태는 파일로). 이 문서에는 아직 정하지 않은 것만 둔다.

## 정한 것 (초안의 남은 결정)
- 첫 판 명령: `select`, `show`, `join`, `diff`, `only`, `stack`, `undo`, `new`, `export` (사용자 결정 2026-11-13). `where-used`, `rollup`은 다음 판.
- 기본 스킬: `pandas-kit` 하나 (4.9KB). 8KB에 가까워지면 작업별로 나눈다 (예: 고르기·보기 / 비교·저장).

## 첫 판에서 가장 단순하게 정한 것 (바꿀 수 있음)
- `select`에 `--file`도 `--from`도 없으면: 만든 표가 있으면 지금 표, 없으면 열린 Excel 통합문서.
- 시트를 안 주면 파일을 열었을 때 보이는 시트.
- 머리글: 칸이 둘 이상 찬 첫 행 (한 칸짜리 제목 행은 건너뜀). 초안의 "내용이 처음 나오는 행"은 BOM 위의 제목을 머리글로 읽어서 바꿈.
- `--where`의 조건이 `--columns`보다 먼저 (남기지 않을 열로도 거름). 글자 비교는 대소문자를 구분.
- `join`은 양쪽에 있는 행만 (inner). 왼쪽 행을 모두 남기는 방식은 요청이 있을 때.
- `diff`는 바뀐 곳마다 한 행 (바뀐 칸마다 한 행). 키가 같은 행이 있으면 멈춤.
- `stack`은 맨 앞에 `표` 열.
- 원본에 칠하는 office-cli 명령은 `next_commands`가 아니라 `confirm_commands` (원본 문서를 바꾸므로, 공통 계약 7번).
- `export`는 기본 `.xlsx`, 작업 폴더 안. 이름만 준 `--save`도 작업 폴더 기준.
- 30MB를 넘는 xlsx는 openpyxl 읽기 전용 모드 (숨긴 행·병합 칸·저장 안 된 수식은 확인하지 않고 알림).
- 긴 작업 나눠서 진행(`CONTINUE:`)은 첫 판에 없음.
- `chart`(사용자 요청으로 첫 판에 더함)는 표를 바꾸지 않아 단계로 남기지 않음 (`undo` 대상 아님). 그림은 PNG만, 같은 x는 합계, 막대 30개·원 12조각까지.

## 남은 결정
- `where-used`, `rollup`의 입력 모양: 레벨 열(`Level` 1~5)로 부모를 찾을지, `Parent` 열을 쓸지, 둘 다 받을지. 같은 하위 조립체가 여러 곳에 쓰일 때 수량 곱하기.
- `replay --file <새 판>`: 같은 단계를 다른 파일에 다시 실행할 때 시트·범위가 달라졌으면 어떻게 할지.
- `CONTINUE:`를 넣을 크기 기준 (회사 PC에서 큰 BOM 읽기 시간을 재고 정함).
- 자유 코드 `eval`을 둘지 (README에만, 대형 모델용).
