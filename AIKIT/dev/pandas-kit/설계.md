# pandas-kit 설계 (초안, 2026-11-13)

사용자와 정한 내용을 구현 전에 모아 둔 문서. 구현하면서 README.md·SKILL.md·CHANGELOG.md로 옮기고, 이 문서는 남은 결정만 남긴다.

## 1. 성격
- 완결형 작업 도구 (ml-kit과 같은 성격). 표 데이터를 단계별로 다룬다. 첫 대상은 BOM 분석.
- 읽기·칠하기·메모(원본 Excel에 쓰는 일)는 office-cli, 계산은 pandas-kit. 도구끼리 import하지 않는다.
- LLM에게 pandas 코드를 짜게 하지 않는다. 정해진 명령만 스킬에 적는다.
  자유 코드 `eval`은 README에만 둔다 (대형 모델용, 결과는 똑같이 한 단계로 기록).
- 폴더: `AIKIT/pandas-kit/` (실행 파일만), `AIKIT/dev/pandas-kit/` (README, CHANGELOG, tests).
  진입점 `pandas_kit.py <명령>`, 공통 런타임 `_pd_runtime.py` (`run_cli`, `JsonArgumentParser`, 복구 함수).

## 2. 대상 파일
- 대상은 xlsx·xlsm·csv 파일. 열린 Excel 문서를 COM으로 다루지 않는다.
- `--file`이 없으면 열린 Excel 통합문서의 경로를 도구가 찾는다 (경로를 얻는 데만 COM 사용, office-cli를 import하지 않고 자기 폴더에 작은 함수).
  - 하나면 그 파일. 여럿이면 `[후보] 1) 2)`와 같은 번호의 `confirm_commands`. 없으면 경로를 물으라고 안내.
- 저장 안 된 문서(`Saved=False`, 저장한 적 없는 새 통합문서 포함)는 읽지 않는다.
  `STOP_RETRY:` "Excel에서 저장한 뒤 같은 명령을 다시 실행". 도구가 대신 저장하지 않는다.
- 원본 파일은 쓰지 않는다. 결과는 새 파일로만. 원본에 칠하기·메모가 필요하면 office-cli 전체 명령을 `next_commands`로 준다.
- csv 인코딩 자동 판별(`read_text_file`). xlsx 수식 칸은 저장된 값으로 읽고, 값이 비어 있는 계산 안 된 수식은 `warnings`.

## 3. 엑셀 위치 기억
- 읽을 때 앵커를 기록: 시트, 머리글 행, 데이터 범위(예: `B5:H230`), 열 이름 <-> 열 글자, 행마다 원래 Excel 행 번호(숨은 열 `_row`).
- `_row`는 거르기·정렬·조인 뒤에도 남는다.
- 사람이 쓰는 주소를 받는다: `C5`, `B5:D20`, 열 글자 `C`, 열 이름, 행 번호. 도구가 앵커로 바꾼다.
  - 머리글 칸을 가리키면 그 열 전체.
  - 읽은 범위 밖이면 멈추고, 읽은 범위와 범위를 넓혀 다시 읽는 전체 명령(`[추천]`)을 준다.
- 결과에도 엑셀 주소를 붙인다. 집계·피벗·새 열처럼 원본에 자리가 없으면 "엑셀 위치 없음(계산한 표)".
- 표 범위 자동 찾기: 내용이 처음 나오는 행이 머리글, 완전히 빈 행에서 끝. 찾은 것을 preview에 적고("B5:H230, 머리글 5행"), 틀릴 때만 `--range`.
- 같은 이름·이름 없는 열은 `Qty_2`, `열_F`로 부르고 열 글자 대응을 기록.

## 4. 값은 바꾸지 않음
- 품번처럼 생긴 열은 글자로 둔다. 숫자 변환은 열 전체가 숫자이고 앞자리 0이 없을 때만. 열마다 읽은 종류를 메타 정보와 preview에 남긴다.
- 공백·대소문자·병합 칸 빈자리를 몰래 고치지 않는다. 병합 칸, 숨긴 행, 자동 필터로 가려진 행은 개수를 `warnings`로.
- 메우기·다듬기는 기록에 남는 명시적 단계(`fill`, `trim`)로만.

## 5. 상태 (파일 방식)
- 작업 폴더: 대상 파일과 같은 폴더의 `pandas_YYMMDDHHMM\` (사용자가 경로를 주면 그 경로, 같은 분에 또 만들면 `_2`).
  대상 파일이 여럿이면 처음 불러온 파일 옆.
- 처음 `select --file`에서 새 작업 폴더를 만들고, 그 뒤 명령은 "지금 작업 폴더"에 이어서 쓴다 (다른 파일을 불러와도 같은 폴더).
  새로 시작은 사용자가 말할 때 `new`, 지난 작업으로 돌아가기는 `--work "<폴더>"`.
- "지금 작업 폴더" 표시와 오류 로그는 도구 데이터 폴더(`C:\AIKIT\pandas-kit\data`, 환경변수 `PANDAS_KIT_DATA_DIR`).
- 작업 폴더 안: 단계 기록(JSON, 원본), 표 스냅샷 `tables/*.pkl`(캐시), 원본별 앵커 메타.
  - 스냅샷이 깨졌거나 pandas 버전이 다르면 버리고 기록을 다시 실행해 만든다. 도구가 만든 자기 작업 폴더의 pickle만 읽는다.
- 원본 변경 감지: 읽을 때 수정 시각·크기를 기록, 다음 명령에서 달라졌으면 `warnings`("원본이 바뀜, 행 위치가 달라졌을 수 있음") + 다시 읽는 명령 `[추천]`.
- `undo`(한 단계씩), `replay --file <새 판>`(같은 단계를 다른 파일에).

## 6. 이름 붙인 표 (df1, df2)
- `select`로 원본 파일(시트·범위)·이미 만든 표·다른 파일에서 영역과 조건을 골라 이름을 붙인다.
  ```
  python "C:\AIKIT\pandas-kit\pandas_kit.py" select --file "BOM.xlsx" --range B5:H230 --where "Level=1;Qty>2" --name df1
  python "C:\AIKIT\pandas-kit\pandas_kit.py" select --from df1 --where "Maker=A|B" --name df2
  ```
- 구분자는 저장소 규칙: 조건 여러 개(그리고) `;`, 또는 `|`, 열 여러 개 `,`.
- `--name`을 빼면 도구가 `df1`, `df2`, ... 순서로 짓고 알린다. `--from`을 빼면 지금 표.
- 표마다 계보 기록 (예: `df2 = df1에서 Maker=A|B, 원본 BOM.xlsx Sheet1 B5:H230`), preview에 한 줄.
- 같은 이름을 다시 만들면 새 단계, 이름은 새 표를 가리킨다. 그 표에서 파생된 표는 다시 계산하지 않고 `warnings`("df2는 옛 df1 기준").
- 두 표 작업 (명령 하나에 결과 표 하나):

  | 명령 | 뜻 |
  |---|---|
  | `join --left df1 --right df2 --on "Part Number"` | 짝 맞춰 붙이기 |
  | `diff --old df1 --new df2 --on "Parent,Part Number"` | 추가·삭제·바뀐 칸 |
  | `only --left df1 --right df2 --on ...` | df1에만 있는 행 |
  | `stack --tables df1,df2` | 위아래로 잇기 |

- 결과에 양쪽 원본 행 번호(`df1 행`, `df2 행`)를 함께 남긴다. 칠할 칸 csv도 파일별로 따로 만든다.

## 7. LLM 출력
- `show`는 최대 20행, Excel 행 번호·열 글자와 함께. 넘으면 `truncated: true` + 전체 결과 csv 경로. 0건은 `"count": 0`과 "찾은 행 없음".
- 열 이름 오타: 같은 뜻 표로 고칠 수 있을 때만 `[추천]`, 철자만 비슷하면 `[후보]`.
- 내보내기는 새 파일에만, 덮어쓰기는 `--overwrite`일 때만, 잠겼으면 시각을 붙인 이름으로 저장.
- 큰 파일은 openpyxl 읽기 전용 모드, 120초 전에 못 끝나면 `CONTINUE:`. 오류 로그에 셀 값은 남기지 않는다.

## 8. 남은 결정
- 첫 판에 넣을 명령 범위 (안: `select`, `show`, `join`, `diff`, `only`, `stack`, `undo`, `new`, `export`, BOM용 `where-used`·`rollup`은 다음 판).
- 기본 스킬 이름과 개수 (스킬 8KB 이하).
