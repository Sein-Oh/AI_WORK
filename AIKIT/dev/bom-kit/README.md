# bom-kit (0.2.1)

BOM 업무 계산 도구입니다. pandas-kit(표를 고르고·비교하는 기반 도구)에 넣지 않는 BOM 업무 규칙을 한 곳에 둡니다
(사용자 결정 2026-11-14). 기본 스킬 `mbom-diff`(두 판 비교)와 `where-used`(쓰인 곳)가 씁니다.

**명령 하나로 끝납니다** (사용자 결정 2026-11-14): Gemma 같은 경량 모델은 여러 단계를 잇다가 중간 명령의 지시(`next_commands`)를 따라가
멈추기 쉬워서, 표 읽기·경로 계산·비교·요약을 도구가 차례로 하고 최종 결과만 돌려줍니다. 원본 엑셀은 쓰지 않습니다.

## 파일
| 파일 | 하는 일 |
|---|---|
| `AIKIT/bom-kit/bom.py` | 진입점. `python bom.py <명령> ...` |
| `AIKIT/bom-kit/_bom_runtime.py` | 공통 런타임 (진입점 아님): `run_cli`, `JsonArgumentParser`, `quote_arg`, 오류 로그, 파일 복구 함수. pandas-kit `_pd_runtime.py`와 같은 이름·같은 동작 (표준 라이브러리만) |
| `tests/` | `python -m pytest -q AIKIT/dev/bom-kit/tests` (샘플은 `AIKIT/dev/pandas-kit/tools/make_mbom_samples.py`) |

필요한 것: 표준 라이브러리, 그리고 같은 `C:\AIKIT` 아래의 pandas-kit (`C:\AIKIT\pandas-kit\pandas_kit.py`, 표 읽기·비교에 실행). `requirements.txt`.
데이터 폴더(오류 로그 `logs/errors.txt`): `AIKIT/bom-kit/data`, 환경변수 `BOM_KIT_DATA_DIR`로 바꿈.

## pandas-kit과의 관계
- import하지 않고 `python pandas_kit.py <명령>`으로 실행만 합니다 (도구 폴더는 단독 배포). 명령마다 1줄 JSON을 읽습니다.
- pandas-kit의 데이터 폴더를 실행마다 따로 씁니다 (`<bom-kit 데이터 폴더>/pandas-kit/runs/<실행>`, 끝나면 지움, pandas-kit 오류 로그는
  `<bom-kit 데이터 폴더>/pandas-kit/logs`로 옮김). 사용자가 pandas-kit으로 하던 지금 작업(지금 표)도, 동시에 도는 다른 bom-kit 실행도 바꾸지 않습니다.
- 결과 파일 위치 (전역 지침 2장 '결과 파일 위치', 사용자 지적 2026-11-14): 사용자가 볼 결과 파일은 **대상 파일과 같은 폴더**에 실행마다
  시각을 붙인 새 이름으로 저장하고(덮어쓰지 않음, R4), 그 경로가 `output_file`입니다. 앞 결과는 모두 남습니다.
  - `diff`: 옛 판 옆 `<옛 판>_<새 판>_비교결과_<시각>.xlsx` (요약 시트, 변경내용 시트)
  - `where-used`: BOM 옆 `<BOM>_쓰인곳_<찾는 말>_<시각>.csv`
  - `history`: 준 파일 옆 `<파일>_변경이력_<시각>.csv`
  같은 초에 같은 이름이면 `_2`.
- 도구가 다시 쓰는 파일은 옛 판 옆 `<옛 판 이름>_bom\` 폴더(표시 파일 `.created_by_bom-kit`, 같은 이름의 다른 폴더가 있으면 `_bom2`):
  diff마다 `diff_<새 판>_<시각>_변경내용.csv`(`changes_file`), `_칠할칸_옛판.csv`·`_칠할칸_새판.csv`(`confirm_commands`가 다음 턴에도 되게),
  `_기록.json`(history가 모음). 지우지 않습니다.
- pandas-kit 작업 폴더(원본 옆 `<파일 이름>_<시각>`)는 캐시라 실행 끝(멈춘 실행 포함)에 지웁니다. 안의 파일이 열려 있으면 반쯤 지우지 않게
  폴더 이름부터 바꿔 보고, 안 되면 그대로 두고 stderr `[WARN]`, `<데이터 폴더>/works.json`에 기억했다가 다음 실행 때 다시 지웁니다.
  pandas-kit 표시 파일이 있는 폴더만 지웁니다.
- pandas-kit 경고는 사실만 옮깁니다 (`옛 판:`, `새 판:`, `BOM:`을 붙임). pandas-kit 명령·옵션을 권하는 문장은 뺍니다 (경량 모델이 그 명령으로 여러 단계를 다시 잇지 않게).
- pandas-kit이 시트·표 범위를 `[후보]`·`[추천]`으로 물으면 같은 값을 넣은 **bom.py 전체 명령**으로 바꿔 줍니다
  (옛 판의 시트는 두 판 공통 `--sheet`, 새 판만이면 `--new-sheet`, 범위는 `--old-range`·`--new-range`, where-used는 `--sheet`·`--range`).
  그 밖의 실패(파일 없음, 저장 안 된 문서 등)는 메시지만 옮깁니다.

## BOM 업무 규칙 (이 도구 한 곳에만)
- 상위 = 위쪽 행 중 가장 가까운, Level이 더 작은 행 (상위 품번 열이 없는 BOM). Level이 두 단계 이상 건너뛰면 `warnings`.
  Level은 숫자(`0`, `1`, `2.0`)와 점 표기(`.1`, `..2` -> 뒤의 숫자, 점만 `..` -> 점 수). 읽지 못한 행이 있으면 preview 첫 줄 `주의:`와 `UNVERIFIED:`.
- 경로 = 최상위부터 품번을 `/`로 이은 것. 같은 상위 아래 같은 품번이 둘 이상이면 모두 `#순번` (`300210#1`, `300210#2`).
  두 판의 짝은 도구 안의 경로 키로 맞춥니다: 늘 `#순번`을 붙이고(한 판에서만 둘이어도 어긋나지 않게), 구분자가 품번의 `/`·`#`과 겹치지 않음.
  화면과 변경내용 파일에는 `/`와 필요한 `#순번`만.
- 제품 1대당 수량 = 그 행과 위쪽 상위들의 수량을 곱한 값 (스크랩·유효 기간·대체 그룹은 보지 않음).
- 두 판 비교: 경로(품번 기준)로 짝을 맞춤. 다른 상위로 옮겨진 품목은 삭제·추가로 둠. 같은 상위 아래 같은 자리(앞이나 뒤의 형제 품번이 같음)에서
  품번이 바뀐 것만 `[대체 후보]` (품명은 보지 않음, 삭제와 추가에 모두 있는 품번은 옮겨진 것이라 짝짓지 않음) (사용자 결정 2026-11-14).
- 상위 삭제 (사용자 결정 2026-11-14): 상위 행만 지워지면 Level로 상위를 정하므로 그 하위가 바로 위의 다른 상위 아래로 붙는다.
  지운 상위의 하위를 행 순서대로 같은 상대 경로(품번)의 추가 행과 짝지어, 절반 이상 짝이 맞으면 `[상위 삭제] <품번>: ... 그 하위 N행은
  새 판에서 <새 상위> 아래에 그대로 있음` 한 줄로 알리고(`counts`의 `상위 삭제`), 짝 맞은 하위는 추가·삭제로 세지도 칠하지도 않는다.
  짝이 없는 하위(그 안의 진짜 삭제·추가)는 따로 알린다. 같은 상위 아래 순서만 바뀐 것은 찾지 않는다.
- 표 안에 빈 행이 있으면 묻지 않고 빈 행까지 한 표로 읽고 `warnings`로 알린다 (사용자 결정 2026-11-14: BOM 가운데 빈 행은 표가 끝난 것이 아님).
  이 규칙은 pandas-kit(0.2.12) 표 찾기에 있고 bom-kit은 그 알림을 옮긴다.
  다른 범위로 읽으려면 `--old-range`·`--new-range`(where-used는 `--range`). diff와 where-used가 같음.
- 열 찾기: Level(`Level`, `레벨` 등), 품번(`Part Number`, `품번`, `자재번호` 등), 수량(`Qty`, `수량` 등), 품명·단위(있으면).
  못 찾거나 준 이름이 없으면 열들을 `[후보]`로, 고른 번호의 `confirm_commands`는 `--level`·`--part`·`--qty`를 넣은 전체 명령.
- 두 판에서 같은 뜻의 열 이름이 다르면(옛 판 `Qty`, 새 판 `수량`) 짝지어 bom-kit이 비교합니다 (`warnings`, 이 열의 바뀐 칸은 칠할 칸 목록에 없음).
  그래도 한쪽에만 있는 열은 비교하지 못한 것이라 preview 첫 줄 `주의:`와 `UNVERIFIED:`.

## 명령
| 명령 | 옵션 | 결과 |
|---|---|---|
| `diff` | `--old`, `--new`, `--sheet` (README에만: `--old-sheet`, `--new-sheet`, `--old-range`, `--new-range`, `--level`, `--part`) | 두 판을 읽고(pandas-kit select·export) 경로 계산, 경로 붙이기(join `엑셀 행`), `diff --on 경로`, 결과 export 뒤 `[대체 후보]`·`[추가]`·`[삭제]`·`[바뀜]` 줄과 옛·새 엑셀 행, `counts`, 끝 줄에 읽은 표. `output_file`(비교 결과 엑셀, 옛 판 옆: 요약 시트와 변경내용 시트, preview 끝 줄에 경로), `changes_file`(변경내용 csv, 결과 폴더), `confirm_commands`(원본에 바뀐 칸 칠하기, office-cli, 사용자가 원할 때만). 0건은 "두 판이 같습니다" |
| `history` | `--file` | 그 파일과 비교로 이어진 판들의 diff 기록(`diff_<새 판>_<시각>_기록.json`, 옛 판 옆 결과 폴더)을 시간순으로 `[비교] <시각> <옛 판> -> <새 판>: <그때의 건수>` 줄과 변경내용을 합친 `<파일>_변경이력_<시각>.csv`(`output_file`, 준 파일 옆). 파일이 그대로인 같은 비교는 마지막 것만. 비교 뒤 원본이 바뀌었거나 없으면 `warnings`. 0건은 `count: 0`과 "비교 기록이 없습니다" |
| `where-used` | `--file`, `--find`, `--sheet` (README에만: `--range`, `--level`, `--part`, `--qty`) | BOM을 읽고 `--find`와 같은 품번(대소문자 무시) 또는 품명에 그 글자가 든 행마다 `[쓰임]` 줄(상위·제품 1대당 수량·경로·엑셀 행), `totals`(품번·단위별 곳 수와 합계), `output_file`(쓰인곳 csv). 0건은 `count: 0`과 "찾지 못했습니다" |

- 출력 상한: `lines` 30줄 (넘으면 `truncated: true`, 전체는 `output_file`, preview 끝 줄 `(나머지 N줄은 <output_file>)`: diff와 where-used가 같음).
- `where-used`에 숨긴 행(자동 필터로 가려진 행 포함)이 걸리면 `warnings`에 그 엑셀 행과 품번 (결과와 제품 1대당 수량에는 넣음).
- 시간: pandas-kit 명령 diff 12개·where-used 3개 (클라우드 diff 약 4초, where-used 약 1초). 명령 실행 도구 120초 안.
- 결과 파일은 다시 읽어 행 수를 확인하면 `VERIFIED`. 저장 대상이 잠겨 있으면 시각을 붙인 새 이름(`recovered`).
