# skill-maker 스킬 (Windows)

스킬은 "이런 요청이 오면 이 순서로 이 명령을 실행하라"를 적은 글 파일(SKILL.md) 하나다. 한 번 등록하면 다음부터 같은 요청을 말로만 해도 같은 방법으로 처리된다.

## 규칙
1. 아래 순서와 명령을 그대로 따른다. 인터넷 검색을 하지 않는다. 스킬 파일의 머리말(`---`, name, description)은 직접 쓰지 않는다: 도구가 붙인다.
2. PowerShell에서는 명령 앞에 전역 지침의 인코딩 줄을 붙인다. 명령은 1번만 실행하고 마지막 1줄 JSON만 읽는다. `confirm_commands`는 사용자 "예" 뒤에만 1번.
3. 스킬 이름은 영문 소문자, 숫자, `-`만 (예: `weekly-report`). 이름과 설명은 사용자에게 보여 주고 확인받는다. 기본 스킬 이름(office-*, ml-*)은 쓸 수 없다.
4. 스킬로 만들 수 있는 것: 이 PC의 도구 명령(다른 스킬의 명령)이나 `C:\AIKIT\data\scripts\`의 파이썬 스크립트로 되는 일. 인터넷, 설치가 필요한 일은 만들지 않는다.

## 스킬 만드는 순서 ("이거 스킬로 만들어줘")
1. 방금 한 작업(또는 사용자가 말한 작업)을 세 가지로 정리해 사용자에게 보여 준다: 언제 쓰는지 / 사용자가 매번 줄 것(파일 경로, 날짜 등) / 실행한 명령 순서.
2. 파이썬 스크립트로 한 작업이면 스크립트가 파일 경로를 코드에 적어 두지 않고 명령 인자(`sys.argv`)로 받게 고치고, `C:\AIKIT\data\scripts\<영문 이름>.py`에 둔 뒤 1번 실행해 되는지 확인한다.
3. 스킬 이름(영문)과 설명(한두 문장: 무엇을 하는지 + 어떤 요청에 쓰는지)을 제안하고 사용자가 "예"라고 하면 다음으로 간다.
4. 파일 쓰기 도구로 본문 파일 `C:\AIKIT\data\scripts\<스킬 이름>_skill.md`(UTF-8)를 아래 "본문 모양"대로 만든다. 사용자가 바꿀 값은 `<엑셀 파일>`처럼 `<...>`로 적는다.
5. 등록한다 (아래 명령). `STOP_RETRY`에 "고칠 것"이 나오면 본문이나 설명을 고쳐 같은 명령을 1번 다시 실행한다.
6. 결과의 `preview`와 `skill_file`, `warnings`를 알리고, "OpenCode를 모두 닫았다가 다시 시작한 뒤 새 대화에서 <설명에 적은 요청>처럼 말하면 됩니다 (그래도 안 보이면 `C:\AIKIT\web.bat stop` 뒤 다시 실행)"라고 안내한다.

## 명령
| 할 일 | 명령 |
|---|---|
| 스킬 등록 | `python "C:\AIKIT\office-cli\skill.py" save --name <스킬 이름> --description "<설명>" --file "C:\AIKIT\data\scripts\<스킬 이름>_skill.md"` |
| 이 프로젝트에서만 쓸 스킬 | 사용자가 "이 프로젝트(폴더)에서만"이라고 할 때만 위 등록 명령 끝에 `--project "<프로젝트 폴더>"` (그 폴더에서 연 OpenCode에서만 보임) |
| 스킬 고치기 | 본문 파일을 고친 뒤 위 명령을 다시 실행한다. "이미 있습니다"가 나오면 사용자에게 묻고 `confirm_commands[0]` |
| 스킬 목록 | `python "C:\AIKIT\office-cli\skill.py" list` (`kind`: 기본 / 사용자 / 프로젝트) |
| 스킬 점검 | `python "C:\AIKIT\office-cli\skill.py" check --name <스킬 이름>` (`problems`를 그대로 알림) |
| 스킬 지우기 | `python "C:\AIKIT\office-cli\skill.py" delete --name <스킬 이름> --dry-run` (확인 뒤 `confirm_commands[0]`. 기본 스킬은 지우지 않음) |

## 본문 모양 (이대로 쓰고 내용만 바꾼다)
```text
# <스킬 제목>

## 언제 쓰나
<어떤 요청에 쓰는지 한두 문장>

## 사용자에게 받을 것
- <엑셀 파일>: 전체 경로. 모르면 실행 전에 묻는다.

## 순서
1. `python "C:\AIKIT\data\scripts\<이름>.py" "<엑셀 파일>"` 을 1번 실행한다.
2. 출력의 결과 파일 경로와 요약을 사용자에게 알린다.

## 주의
- 원본 파일은 고치지 않는다. 실패하면 오류 줄을 그대로 알리고 멈춘다.
```
- 도구 명령으로 한 작업이면 순서에 그 명령을 전체 경로 그대로 적는다 (예: `python "C:\AIKIT\office-cli\excel.py" stats --target "<엑셀 파일>" --by 부서`).
- 본문은 짧게 쓴다 (8KB 이하, 이모지·장식 기호 없이). 삭제·덮어쓰기·메일 발송이 든 작업은 "실행 전에 사용자에게 묻는다"를 순서에 적는다.

## 결과 처리
- `agent_directive` 첫 단어별 행동은 전역 지침 4장대로. `[추천]`(이름을 규칙에 맞게 고친 명령)은 그대로 1번 실행한다.
- 등록한 스킬이 안 보이면 OpenCode를 다시 시작했는지 묻고, `check`로 점검한다.
