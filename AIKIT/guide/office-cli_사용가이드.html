office-cli 사용 가이드

엑셀, 워드, 파워포인트, 아웃룩, 문서 검색을 AI 에이전트(Gemma)에게 말로 시키는 방법 | 베타테스트용 | office-cli 1.6.4

office-cli는 에이전트가 Office 문서를 직접 읽고 고칠 수 있게 해 주는 도구입니다. 채팅에 하고 싶은 일을 평소 말투로 쓰면 에이전트가 알맞은 도구를 골라 실행하고 결과를 알려 줍니다. 이 가이드는 채팅에 무엇을 어떻게 쓰면 되는지를 사례로 보여 줍니다. 요청 예시의 "복사" 버튼으로 가져가 파일 이름과 값만 바꿔 쓰세요.

1. 이렇게 요청하세요

1.1 할 수 있는 일

엑셀

표 읽기, 조건에 맞는 행 찾기, 값과 수식 넣기, 여러 칸 한 번에 쓰기, 수식을 값으로, 차트 만들기, 서식 꾸미기, 정렬, 행·열 넣기·지우기, 칸 메모(검토 의견), 규격서와 대조, 찾아 바꾸기, 시트 추가, 저장·다른 이름으로 저장, CSV/PDF로 저장

표 집계

엑셀·CSV 표의 합계·평균·최소·최대·건수, 부서별 같은 묶음별 집계, 중복 행 찾기

워드

목차·장절·쪽 단위로 읽기, 내용과 그림 넣기, 양식 채우기, 찾아 바꾸기, 단락 지우기, 표 행 넣기·지우기, 단락 서식(정렬·글꼴·크기), 검토 메모 달기·답글·지우기, 변경 추적 기록 보기, PDF 저장

파워포인트

슬라이드 읽기, 새 슬라이드 만들기(글머리, 카드, 그림, 표), 있던 도형의 글 바꾸기·옮기기·크기, 발표자 노트 읽기·쓰기, 슬라이드 복제·순서 바꾸기, PDF 저장

앱 사이 옮기기

엑셀 차트를 워드/PPT에 그림으로, 엑셀 표를 워드/PPT 표로, 워드/PPT의 표·글을 엑셀로

아웃룩

보고 있는 메일 읽기, 메일 찾기(기간, 보낸 사람, 첨부 있는 메일만), 대화 전체 보기, 일정 보기·만들기·지우기, 첨부 내려받기와 읽기, 내려받은 eml 폴더 검색, 답장·전달·새 메일 초안(문서 첨부) (보내기는 분명히 요청할 때만)

문서 검색

PDF, HWP, 워드, 엑셀 등을 등록해 두고 단어를 찾거나 장절 목록을 보고 장절을 읽으면 "어느 파일 몇 쪽, 몇 장 몇 절"인지 근거와 함께 알려 줌

되돌리기

도구가 문서를 고치기 전에 자동으로 저장해 둔 지점으로 되돌리기

도구에 없는 일도 있습니다. 인쇄, 회의 요청 등은 에이전트가 "그 앱에서 직접 하세요"라고 안내하고, 피벗 테이블처럼 문서를 바꾸는 일은 확인을 받은 뒤 처리하고, 여러 파일 합치기나 통계 같은 일은 에이전트가 파이썬 스크립트를 짜서 처리합니다. 자세한 목록은 10장을 보세요.

1.2 요청 문장의 기본 틀

요청 한 문장에 아래 네 가지가 들어 있으면 에이전트가 되묻지 않고 바로 실행합니다.

요소쓰는 법예
어느 문서열려 있으면 "열린 엑셀", "지금 보고 있는 워드". 닫혀 있으면 전체 경로. 같은 앱 문서가 여러 개 열려 있으면 파일 이름열린 엑셀 / C:\업무\보고서.docx / 월간보고.xlsx
어디시트, 셀 범위, 장절 번호, 쪽, 슬라이드 번호, 기준이 되는 문구Sheet1 A1:D20 / 2.1절 / 5쪽 / 3번 슬라이드 / "시험 결과" 제목 뒤
무엇을읽기, 넣기, 바꾸기, 만들기, 옮기기, 찾기읽어줘 / 넣어줘 / 바꿔줘 / 만들어줘
어떻게 (선택)결과물의 모양, 이름, 색, 저장 위치꺾은선, 제목은 월별 매출 / navy 테마 / C:\업무\결과.pdf 로

열린 엑셀 Sheet1 A1:B13으로 꺾은선 차트 만들어줘. 제목은 월별 생산량

파일의 전체 경로 복사하기: 탐색기에서 대상 파일을 마우스 오른쪽 버튼으로 클릭하고 "경로로 복사"를 누른 뒤, 채팅에 붙여 넣으세요. 경로 앞뒤에 따옴표가 함께 붙어도 괜찮습니다.

1.3 요청을 잘하는 요령

요령좋은 예아쉬운 예
대상을 분명히"열린 엑셀의 Sheet1 A1부터", "C:\업무\보고서.docx""그 파일", "아까 거"
범위를 구체적으로"A1:D20 읽어줘", "2.1절만 읽어줘""앞부분 좀 봐줘"
한 번에 한 가지씩"표 넣어줘" 다음에 "차트 만들어줘"표, 차트, 서식, 메일까지 한 문장에
결과물 모양을 말하기"꺾은선 차트, 제목은 월별 매출""보기 좋게 해줘"
표나 긴 글은 채팅에 그대로 붙여 넣기요청 다음 줄부터 표·목록을 붙여 넣기 (쉼표나 탭으로 칸 구분)"메일에 있는 그 표"(에이전트가 볼 수 없는 곳)
덮어쓰기·삭제·발송은 말로 분명히"기존 노트를 바꿔줘", "보내줘""알아서 정리해줘"

긴 대화를 이어 가면 에이전트가 앞 내용을 헷갈릴 수 있습니다. 작업 하나가 끝나면 새 대화에서 다음 요청을 시작하세요.

1.4 에이전트의 답에 이어서 말하기

에이전트의 답뜻이렇게 답하세요
완료 "~했습니다"도구가 작업 후 다시 읽어 확인까지 마침마음에 들지 않으면 "방금 한 거 되돌려줘"
확인 못함실행은 됐지만 결과를 다시 읽어 보지 못함문서를 직접 확인
후보 선택 "[후보] a, b"같은 이름·문구가 여러 곳이라 추측하지 않고 멈춤"2번", "Sheet2로"처럼 하나 고르기
진행 확인 "진행할까요?"삭제, 덮어쓰기, 새 시트, 메일 발송처럼 되돌리기 어려운 일대상을 확인하고 "예" 또는 "아니오"
직접 하세요 "도구에 없는 기능"인쇄, 회의 요청, 메일 이동처럼 도구가 하지 않기로 한 일(10장)안내받은 메뉴에서 직접 하기. 다시 시켜도 결과는 같음
실패파일이 없거나 값이 잘못됨안내에 따라 요청을 고쳐 다시. 이해되지 않으면 그대로 피드백(11장)

1.5 도구가 알아서 지키는 것

  • 고치기 전에 자동 저장 지점: 엑셀·워드·PPT를 고치기 전에 사본을 만들어 둡니다(문서마다 최근 5개).
  • 덮어쓰지 않음: 같은 이름의 파일이 있거나 열려 있으면 이름 뒤에 시각을 붙인 새 파일로 저장하고 알려 줍니다. 기존 시트나 노트를 바꾸는 일은 허락할 때만 합니다.
  • 추측하지 않음: 없는 시트에 쓰라고 하면 새 시트를 몰래 만들지 않고 묻습니다 (있는 시트에 쓸지, 새 시트를 만들지 번호로 고르게 함).
  • 지우기 전에 미리 보여 줌: 행·열, 단락, 표 행, 메모, 일정, 슬라이드를 지우거나 수식을 값으로 바꿀 때는 무엇이 바뀌는지 먼저 보여 주고 "예"를 받은 뒤에 합니다. "묻지 말고 해줘"라고 해도 삭제·덮어쓰기·메일 발송은 늘 묻습니다.
  • 제한된 보기와 시트 보호는 풀지 않음: 메일 첨부나 내려받은 파일이 제한된 보기로 열려 있거나 시트가 보호되어 있으면 아무것도 바꾸지 않고 알려 줍니다. 노란 줄의 [편집 사용]을 누르거나(없으면 검토 > 시트 보호 해제) "눌렀어"라고 답하면 이어서 합니다. 읽기는 그대로 됩니다.
  • 메일은 초안까지만: "보내줘"라고 분명히 말하지 않으면 작성 창만 띄웁니다.
  • 읽기는 화면을 건드리지 않음: 시트, 스크롤, 슬라이드 위치가 그대로입니다.

2. 엑셀

엑셀 작업은 지금 보고 있는 통합문서가 기본 대상입니다. 다른 열린 문서는 이름으로, 닫힌 파일은 전체 경로로 알려 주세요.

2.1 내용 읽기, 찾기, 행 수 세기

열린 엑셀의 표 읽기

이럴 때: 표 내용을 요약하거나, 특정 값을 확인하고 싶을 때

열린 엑셀 A1:F30 읽고 어떤 내용인지 요약해줘

C:\업무\매출현황.xlsx 의 2024 시트 내용 보여줘

표 내용과 행 수를 알려 주고, 요청에 따라 요약합니다. 화면은 움직이지 않습니다.

특정 글자가 어디 있는지 찾기

열린 엑셀에서 "미입고"가 들어간 칸 찾아줘

그 글자가 든 칸의 주소(예: Sheet1!D14)와 값을 알려 줍니다.

수식 보기

이럴 때: 값이 어떤 수식으로 계산됐는지 확인하고 싶을 때

열린 엑셀 A1:F30의 수식 보여줘

수식이 든 칸마다 주소, 수식(예: =SUM(B2:B4)), 계산된 값을 알려 줍니다. 수식이 없으면 없다고 알려 줍니다. 닫힌 xlsx 파일도 엑셀 없이 읽습니다.

조건에 맞는 행만 보기

이럴 때: 큰 표에서 금액이 얼마 이상인 행, 특정 부서의 행만 보고 싶을 때

열린 엑셀에서 금액이 100 이상이고 부서가 영업인 행만 보여줘

열린 엑셀에서 부서가 영업이거나 개발인 행만 보여줘

열린 엑셀에서 비고에 "지연"이 들어간 행만 보여줘

머리글 행을 기준으로(표 위에 제목 행이 있어도 머리글을 찾아 줌) 조건에 맞는 행과 그 행 번호를 알려 줍니다. "그리고"와 "또는"을 함께 써도 됩니다. 이상·이하·같음·다름, "포함"과 "포함 안 함"도 됩니다. 맞는 행이 없으면 0건이라고 알려 줍니다. 닫힌 xlsx·CSV 파일도 됩니다.

CSV 파일 읽기, 행 수 세기

C:\업무\주문내역.csv 몇 행인지 세줘

엑셀 없이 파일을 읽어 행 수를 알려 줍니다. 한글 인코딩(UTF-8, CP949)도 자동으로 맞춥니다.

시트와 차트 구성 보기

열린 엑셀에 시트가 몇 개고 각각 어디까지 데이터가 있는지 알려줘

시트별 사용 범위와 차트 목록을 알려 줍니다.

2.2 표 입력하기

대화창에 적은 표를 엑셀에 넣기

열린 엑셀 A1부터 이름, 부서, 점수 표 넣어줘. 홍길동, 생산1팀, 90 김철수, 품질팀, 85 이영희, 생산2팀, 92

에이전트가 표를 파일로 정리한 뒤 엑셀 A1부터 넣고, 넣은 범위를 다시 읽어 확인합니다.

엑셀이나 메모장에서 복사한 표를 그대로 붙여 넣어도 됩니다. 쉼표나 탭으로 칸이 나뉘어 있으면 됩니다.

기존 표 아래에 이어 붙이기

열린 엑셀 표 맨 아래에 박민수, 생산1팀, 88 추가해줘

표의 마지막 행 다음 줄에 이어서 씁니다. 머리글은 다시 쓰지 않습니다.

다른 시트나 새 시트에 넣기

요약 시트 B2부터 이 표 넣어줘 (항목, 수량 / 볼트, 120 / 너트, 80)

"집계"라는 새 시트를 만들어서 A1부터 넣어줘

있는 시트면 바로 넣습니다. 없는 시트 이름을 말하면 새로 만들지 묻고, "새로 만들어"라고 답해야 만듭니다.

여기저기 떨어진 칸에 각각 값 넣기

C6에 ft, C7에 ℃, 계산기 시트 C11에 20 넣어줘

칸마다 따로 실행하지 않고 한 번에 넣은 뒤 모두 다시 읽어 확인합니다. 이미 값이 든 칸이 있으면 그 칸들을 한꺼번에 보여 주고 한 번만 묻습니다. =로 시작하는 값은 수식으로 넣습니다. 잘못 넣었으면 되돌리기 한 번으로 모두 돌아갑니다.

제한된 보기로 열린 파일과 보호된 시트(검토 > 시트 보호)는 아무것도 바꾸지 않고 알려 줍니다. 도구는 보호를 풀거나 암호를 묻지 않습니다. 창 위 노란 줄에 [편집 사용]이 있으면 누르고, 없으면 시트 보호를 직접 푼 뒤 "풀었어"라고 답하면 같은 작업을 이어서 합니다. 잠기지 않은 입력 칸이 있으면 그 칸 목록을 보여 주니 그중에서 골라도 됩니다. 엑셀이 받지 않는 수식(한글 함수 이름, ; 구분 등)은 어느 칸의 어떤 수식인지 알려 주고, 먼저 쓴 칸은 원래대로 돌려 놓습니다.

01234 같은 앞자리 0 코드, 15자리가 넘는 번호, 1-2처럼 엑셀이 날짜로 바꿔 버리는 글자는 도구가 글자 그대로 넣습니다.

2.3 수식 넣기

한 칸 또는 여러 칸에 수식

열린 엑셀 D2:D50에 =B2*C2 수식 넣어줘

범위 전체에 넣고 행 번호는 자동으로 맞춰집니다(D3은 =B3*C3).

절대참조($)가 들어간 수식

E2:E50에 =D2/$D$51 수식 넣어줘

$ 표시가 사라지지 않게 그대로 넣습니다.

계산용 표를 수식으로 만들기

열린 엑셀 A1:B101에 x와 sin(x) 표를 수식으로 만들어줘. x는 0부터 4π까지 100칸으로

머리글과 열마다 수식을 넣어 표를 만듭니다. 이어서 차트를 요청하면 그래프가 됩니다.

수식을 값으로 바꾸기

  • 지원 형식: PDF, HWP, HWPX, 워드(DOCX, DOCM), 파워포인트(PPTX, PPTM), 엑셀(XLSX, XLSM), CSV, TXT, MD, 메일(EML)

10. 자주 묻는 질문과 문제 해결

웹 화면(web.bat)에서 새 세션이 만들어지지 않아요.

웹 화면은 대화(세션)를 프로젝트 폴더 안에 만듭니다. 처음 쓰는 PC는 폴더가 없어 새 세션이 만들어지지 않습니다. 처음 한 번 화면에서 프로젝트 열기로 C:\AIKIT 폴더를 고른 뒤 새 세션을 만드세요. 다음부터는 그 폴더가 목록에 남습니다. 파이썬을 못 찾거나 새 스킬이 안 보이면 C:\AIKIT\web.bat stop을 실행한 뒤 web.bat을 다시 실행하세요.

엉뚱한 문서에 작업했어요.

"방금 한 거 되돌려줘"로 되돌린 뒤, 문서 이름이나 전체 경로를 넣어 다시 요청하세요. 같은 앱의 문서가 여러 개 열려 있으면 이름을 꼭 말해 주세요.

"같은 이름의 문서가 여러 개"라며 멈췄어요.

도구가 추측하지 않고 후보를 보여 준 것입니다. 후보 중 맞는 것을 골라 답하면 이어서 진행합니다.

저장했다는데 파일 이름이 달라요.

같은 이름의 파일이 있거나 열려 있어서 새 이름(시각이 붙은 이름)으로 저장한 것입니다. 에이전트가 알려 준 실제 경로를 확인하세요. 기존 파일을 바꾸고 싶으면 "덮어써줘"라고 분명히 말해야 합니다.

에이전트가 같은 말을 반복하거나 이상한 글자를 계속 써요.

대화가 너무 길어진 경우가 많습니다. 새 대화를 열고 다시 요청하세요.

에이전트가 직접 파이썬 코드를 짜려고 해요.

도구에 없는 일(예: 여러 파일 합치기, 통계 계산, 그래프를 그림 파일로 만들기, 글 정리·변환)은 에이전트가 "도구에 없는 기능이라 파이썬으로 직접 처리합니다"라고 알리고 스크립트를 짜서 하는 것이 정상입니다. 이때 원본 파일은 고치지 않고 결과를 원본 옆에 새 이름으로 저장해 경로를 알려 줍니다.

도구에 있는 일인데 코드를 짜려고 하면 "excel-kit 스킬로 해줘"처럼 작업에 맞는 스킬 이름을 말해 주세요: 엑셀은 excel-kit, 표 집계·중복 찾기는 stats-kit, 워드는 word-kit, PPT는 ppt-kit, 메일·일정은 outlook-kit, 문서 검색·규격 대조는 search-kit. 도구를 쓰면 저장 후 확인, 되돌리기 지점, 덮어쓰기 방지가 함께 됩니다.

도구 명령이 없는 일은 어떻게 되나요?

두 가지는 따로 다룹니다. 그 밖의 일(여러 파일 합치기, 통계 등)은 에이전트가 파이썬으로 처리합니다.

종류일에이전트가 하는 것
확인 뒤 함변경 내용 수락·거부, 피벗 테이블, 데이터 유효성, 이미 있는 차트 고치기무엇을 바꿀지 보여 주고 "예"를 받은 뒤 바꿈. 저장은 하지 않으니 확인하고 직접 저장하세요 (되돌리기가 안 될 수 있음)
하지 않음인쇄, 회의 요청(참석자 초대), 메일 이동·분류·플래그, 반복 일정·회의 지우기그 앱에서 직접 하라고 안내 (되돌릴 수 없거나 다른 사람에게 가는 일)

"제한된 보기" 또는 "시트 보호"라며 아무것도 안 바꿨어요.

메일 첨부나 내려받은 파일은 제한된 보기로 열려 고칠 수 없습니다. 창 위 노란 줄의 [편집 사용]을 누르고, 그 줄이 없으면 검토 > 시트 보호 해제로 직접 푼 뒤 "눌렀어"(또는 "풀었어")라고 답하면 같은 작업을 이어서 합니다. 에이전트는 보호를 풀거나 암호를 묻지 않습니다.

에이전트가 자꾸 "진행할까요?"라고 물어요.

파일·시트·슬라이드·단락·일정 삭제, 기존 파일이나 값 덮어쓰기, 메일 발송, 말하지 않은 새 시트 만들기는 대상을 보여 주고 "예"를 받은 뒤에만 합니다. "묻지 말고 해줘"라고 해도 이 일들은 늘 묻습니다. 대상을 확인하고 "예"라고 답하세요.

에이전트가 따르는 지침과 스킬 파일은 어디에 있나요?

"지침과 스킬 파일 위치 알려줘"라고 물으면 에이전트가 전역 지침, 스킬 파일, 오류 기록의 위치를 그대로 알려 줍니다.

메일이 자동으로 나가지 않을까 걱정돼요.

"보내줘"라고 분명히 요청하지 않으면 작성 창만 뜹니다. 보내 달라고 한 경우에도 받는 사람·참조·제목을 보여 주고 "예"를 받은 뒤에 보냅니다.

검색 결과가 하나도 없어요.

도구가 이미 일부 단어만 맞는 곳과 한 글자 다른 낱말까지 넓혀 찾은 결과입니다(7.4절). 검색어를 짧게 줄이거나(예: "내전압 시험" -> "내전압"), "또는"으로 비슷한 말을 함께 찾거나, 동의어를 등록해 보세요. 스캔 PDF는 검색되지 않습니다.

문서를 열어 두었는데 "열려 있는 문서가 없다"거나 "관리자 권한"이라고 해요.

OpenCode를 관리자 권한 PowerShell에서 실행하면 Windows가 일반 권한으로 연 Office 문서를 보여 주지 않습니다. 관리자가 아닌 일반 PowerShell 창에서 OpenCode를 다시 실행하세요.

"설치 명령"을 알려 주며 멈췄어요.

그 형식을 읽는 데 필요한 파이썬 라이브러리가 이 PC에 없다는 뜻입니다. 에이전트는 직접 설치하지 않습니다. 알려 준 명령(python -m pip install ...)을 PC 관리자에게 전달해 설치한 뒤 다시 요청하세요.
