ml-kit 사용 가이드

엑셀 데이터로 예측 모델을 만들고, 새 조건의 결과를 예측하고, 보고서를 만드는 방법 | 베타테스트용 | ml-kit 2.9.91

ml-kit은 엑셀이나 CSV로 모아 둔 과거 데이터에서 규칙을 스스로 배워, 새로운 조건에서 결과가 어떻게 될지 예측하는 도구입니다. 채팅에 "이 파일로 수율 예측 모델 만들어줘"처럼 쓰면, 도구가 데이터 정리부터 모델 비교, 결과 확인, 보고서 작성까지 알아서 합니다. 이 가이드는 채팅에 무엇을 어떻게 쓰면 되는지를 사례로 보여 줍니다. 요청 예시의 "복사" 버튼으로 가져가 파일 경로와 컬럼 이름만 바꿔 쓰세요.

1.2 ml-kit으로 할 수 있는 일

모델 만들기

데이터 파일과 타겟만 알려 주면 도구가 입력을 고르고, 5가지 방식의 모델을 경쟁시켜 가장 잘 맞히는 것을 고릅니다.

학습용 데이터셋 만들기

"반응온도 180 이상만", "15행, 27행 빼고"처럼 말하면 원본은 그대로 두고 학습용 새 파일을 만들어 줍니다.

성능 높이기

"성능 올려봐"라고 하면 도구가 개선 방법을 정해 다시 학습하고 점수 변화를 알려 줍니다. 더 나아지지 않으면 스스로 멈춥니다.

예측하기

조건 한 건을 말로 넣거나, 새 조건이 여러 행 든 엑셀 파일을 통째로 예측합니다. 예측 범위와 실측 비교값도 함께 줍니다.

조건 찾기

목표값이 되는 입력값, 입력을 바꿔 가며 본 변화, 제약 안에서의 최적 조건, 다음에 해 볼 실험 조건을 찾아 줍니다.

보고서와 성능예측표

판정(적합/조건부/부적합), 성능 그래프, 영향 큰 피처가 담긴 워드 보고서와, 엑셀만으로 예측하는 계산기(성능예측표)를 만듭니다.

경고 받기

학습 범위를 벗어난 입력, 처음 보는 종류, 빈 값, 확신이 낮은 예측을 알려 줍니다.

기록 관리

모든 학습 기록이 버전별로 남습니다. 예측과 보고서는 마지막에 학습한 버전(최종 버전)을 씁니다.

표 보간·반대 찾기

모델 없이 표에서 사잇값을 구하거나, 목표값이 되는 조건을 찾습니다. 예측 결과 검증용.

2. 데이터 준비

2.1 이런 모양이면 됩니다

  • 한 행 = 한 건(한 번의 생산, 한 개의 제품, 하루의 기록), 한 열 = 한 항목인 표.
  • 파일 형식: 엑셀(.xlsx) 또는 CSV.
  • 머리글이 1행이 아니어도 됩니다. 보고서 형식처럼 위에 제목, 결재란, 빈 행이 있어도 도구가 머리글을 찾습니다. 단위 행이 따로 있으면 알려 주세요(2.3).
  • 시트가 여러 개인 엑셀은 첫 시트를 읽습니다(첫 시트가 표지이고 데이터 시트가 하나뿐이면 그 시트). 다른 시트를 쓰려면 "2월 시트로"처럼 시트 이름을 말하세요.
  • 합계·평균 행이 있어도 됩니다. 칸 글자가 합계, 총계, 평균, 소계, 계, Total, Sum, Average인 행은 도구가 학습에서 빼고 행 번호를 알려 줍니다(2.4).
  • 빈 칸이 조금 있어도 됩니다. 피처의 빈 칸은 자동으로 채우고, 타겟이 빈 행은 학습에서 뺍니다.
  • 날짜 열, 글자 열(라인, 설비, 작업자)도 피처로 쓸 수 있습니다. 날짜는 연·월·요일·시각으로 나눠 씁니다.
  • % 값은 화면에 보이는 숫자로 읽습니다. CSV의 11.9%와 엑셀 백분율 서식 칸(화면 11.9%)은 모두 11.9입니다. 한 열에 11.9%와 0.119처럼 배율이 다른 값이 섞여 있으면 멈추고 알려 주니, 열 전체를 한 가지 형식으로 맞춰 주세요.

행이 많을수록, 결과에 실제로 영향을 주는 열이 들어 있을수록 예측이 정확해집니다. 수십 행으로도 학습은 되지만 점수가 낮게 나올 수 있습니다.

2.4 이상치와 합계 행은 지우지 마세요 ("제외" 열)

엑셀에서 이상해 보이는 행을 지울 필요가 없습니다. 도구가 아래처럼 자동으로 판단해 학습에서 빼거나 알려 주고, 뺀 행 목록을 함께 줍니다. 원본 파일은 고치지 않습니다.

행의 모습도구의 처리
타겟 값이 다른 행들과 크게 동떨어진 행학습에서 뺌 (자동 이상치)
입력 값이 오타 수준으로 동떨어진 행 (예: 18.5를 185로 적음)학습에서 뺌 (자동 이상치)
입력 값이 드물지만 오타 수준은 아닌 행 (예: 일부러 해 본 고농도 조건)학습에 그대로 쓰고 "드문 입력 조건 N행"으로 행 번호를 알려 줌
칸 글자가 합계, 총계, 평균, 소계, 계, Total, Sum, Average인 행학습에서 빼고 행 번호를 알려 줌

자동 판단을 바꾸고 싶을 때는 데이터의 "제외"라는 열을 씁니다.

목록을 보고 빼면 안 되는 행이 있으면 원본 엑셀의 "제외" 열에 포함이라고 쓰고 저장한 뒤 다시 학습을 요청하세요. 행이 적은 데이터에서는 일부러 해 본 극단 조건도 오타처럼 보여 빠질 수 있으니, 그런 행에도 포함을 적어 주세요. 이상치 후보가 전체의 10%를 넘으면 원래 넓게 퍼진 데이터로 보고 자동으로 빼지 않습니다.

"제외" 열은 뺄 행에만 이유를 적고 나머지는 비워 두세요. 모든 행에 O/X를 채우면 대부분이 "뺄 행"으로 읽혀 도구가 멈추고 알려 줍니다. N, No, 아니오, -, N/A는 표시로 보지 않습니다.

2.5 일부 행만 학습하거나 행을 빼고 학습 (학습용 데이터셋)

"B라인만 학습", "15행은 빼고 학습"처럼 행을 골라 학습하고 싶을 때도 데이터 파일을 직접 고치지 않습니다. 에이전트가 원본 옆에 학습용 새 파일(데이터셋)을 만들고, 그 파일로 학습합니다. 원본은 그대로입니다.

행 빼기<원본>_제외1.csv (모든 행 + 뺄 행의 "제외" 열에 이유)표시한 행을 빼고 학습하고, 뺀 행은 따로 채점해 "제외 행 포함" 점수로 알려 줌(4.1)

10. 자주 묻는 질문과 문제 해결

"컬럼을 찾을 수 없습니다"라고 나와요.

단위만 뺀 이름(반응온도 = 반응온도(°C))은 도구가 알아서 맞춥니다. 비슷한 이름이 있으면 다른 항목일 수 있어 추측하지 않고 "[후보] 1) ... 2) ..."로 보여 주니, 맞는 번호를 골라 답하세요. 후보가 없으면 "컬럼 이름부터 보여줘"로 정확한 이름을 확인하세요. 머리글이 1행이 아닌 파일이면 몇 행인지 알려 주세요.

내가 넣지 말라고 한 적 없는 열이 빠졌어요. / "의심 입력"이라고 나와요.

피처를 말하지 않으면 도구가 ID·일련번호, 값이 하나뿐인 열, 빈 칸이 많은 열, 타겟과 같은 값인 열, 종류가 너무 많은 글자 열(비고 등)을 빼고 이유를 알려 줍니다. 꼭 넣어야 하는 열이면 "피처는 A, B, C"처럼 직접 말하세요. 직접 말한 피처 중 ID나 타겟과 같은 값으로 보이는 것은 빼지 않고 "의심 입력"으로만 알려 주니, 맞다면 "OO는 빼고 다시 학습해줘"라고 하세요.

이상치를 엑셀에서 지우고 학습해야 하나요?

지우지 마세요. 도구가 자동으로 찾아 빼고, 이상치를 포함한 검증 점수도 함께 알려 줍니다. 합계·평균 행도 자동으로 뺍니다. 자동으로 빠졌지만 꼭 넣어야 할 행은 "제외" 열에 "포함"을 적으세요(2.4절).

특정 행을 빼거나 일부 행만 학습하고 싶어요.

데이터 파일을 고치지 말고 "생산효율 90 초과는 빼고 학습해줘", "15행, 27행 빼고 학습해줘", "B라인만 뽑아서 학습해줘"처럼 요청하세요. 에이전트가 원본 옆에 학습용 새 파일을 만들고 그 파일로 학습합니다(2.5절).

예측이나 보고서는 어느 버전으로 만들어지나요?

그 데이터 파일로 마지막에 학습한 버전(최종 버전)입니다. 점수가 가장 좋았던 버전을 자동으로 고르지 않습니다. 다른 버전을 쓰려면 "v2로 예측해줘", "v2로 보고서 만들어줘"처럼 말하세요. 어떤 버전이 있는지는 "학습 기록 보여줘"로 볼 수 있습니다.

점수가 0.5도 안 나와요.

"성능 더 올려봐"를 먼저 해 보세요. 도구가 "더 나아지지 않음"이라고 멈췄는데도 낮으면 결과에 영향을 주는 항목이 데이터에 없거나, 행이 부족한 경우가 많습니다. 공정 담당자와 함께 빠진 요인이 있는지 살펴보세요.

학습이 너무 오래 걸려요. / "아직 진행 중"이라고만 나와요.

수만 행 데이터는 몇 분 걸릴 수 있습니다. 타겟이 여러 개인 학습, 보고서와 성능예측표는 도구가 한 일을 저장하며 나눠서 진행하고, 에이전트가 같은 명령을 이어서 실행합니다(7장). 에이전트가 결과를 기다리는 중이니 중간에 다른 요청을 넣지 말고 기다리세요. 버전 번호는 끝날 때 한 번만 붙습니다. 10분이 넘으면 피드백으로 알려 주세요.

같은 버전 이름으로 다시 학습하고 싶어요.

보통은 새 버전으로 저장됩니다. 꼭 바꿔야 하면 "v1을 다시 학습해서 바꿔줘"라고 분명히 말하세요. 바뀔 파일을 먼저 보여 주고 "예"라고 답해야 바꿉니다(3.5절).

내가 정한 계산식으로 파생변수를 만들고 싶어요.

"온도/압력 비율을 입력으로 넣어줘", "반응온도를 압축압력으로 나눈 값도 넣어서 다시 학습해줘"처럼 말하면 됩니다(3.4절). 예측할 때와 성능예측표에서는 같은 식을 도구가 다시 계산하므로 원래 입력만 넣으면 됩니다.

한 건 예측에서 "어느 종류인지" 물으며 멈췄어요.

라인, 설비 같은 글자 입력에 학습 때 없던 값을 말했거나 빠뜨린 경우입니다. 없던 값으로 예측하면 결과가 조용히 틀리므로, 보여 준 종류 중에서 번호로 골라 답하세요(6.1절). 정말 새 종류라면 그 종류의 데이터를 모아 다시 학습해야 합니다.

성능예측표가 만들어지지 않았어요.

입력에 날짜 열이 있는 모델과 등급(분류) 타겟은 성능예측표를 만들지 않습니다. 까닭은 보고서를 만들 때 함께 알려 주고 보고서 요약에도 적힙니다. 날짜 열을 뺀 피처로 다시 학습하면 만들 수 있습니다(7-B장).

성능예측표의 값이 예측 결과와 같은가요? 입력을 줄일 수 있나요?

성능예측표는 모델을 엑셀 수식으로 그대로 옮긴 것이라 값이 모델 예측과 같습니다. 입력도 모델의 입력 그대로라 따로 고를 수 없습니다. 입력을 줄이려면 그 피처로 다시 학습한 뒤 다시 만드세요.

결과 파일은 어디에 저장되나요?

학습 결과, 보고서, 성능예측표, 조건별 예측 표, 실험 제안 표는 데이터 파일 옆 <데이터파일이름>_ml_data 폴더에, 파일 예측 결과는 예측한 새 파일 옆에, 학습용 데이터셋은 원본 옆에 저장됩니다. 저장할 곳을 이름만 말하면 데이터 파일 옆에 저장됩니다. 에이전트가 알려 주는 경로를 그대로 쓰세요.

"설치 명령"을 알려 주며 멈췄어요.

그 기능에 필요한 파이썬 라이브러리가 이 PC에 없다는 뜻입니다. 에이전트는 직접 설치하지 않습니다. 알려 준 명령(python -m pip install ...)을 PC 관리자에게 전달해 설치한 뒤 다시 요청하세요.

CSV를 엑셀로 열면 한글이 깨져요.

도구가 저장하는 CSV는 엑셀에서 바로 열리도록 BOM이 붙은 UTF-8로 저장합니다. 다른 프로그램에서 만든 CSV가 깨지면 엑셀의 "데이터 > 텍스트/CSV"로 불러오며 인코딩을 UTF-8로 고르세요.

에이전트가 같은 말을 반복하거나 이상한 글자를 계속 써요.

대화가 길어진 경우가 많습니다. 새 대화를 열고, 데이터 파일 경로를 다시 알려 주며 이어서 요청하세요. 학습 기록은 파일로 남아 있어 사라지지 않습니다.

에이전트가 직접 파이썬 코드를 짜려고 해요.

학습, 예측, 보고서처럼 이 가이드에 있는 일이면 "ml-kit 스킬로 해줘"라고 말해 주세요. 도구를 쓰면 학습 기록, 경고, 보고서가 함께 관리됩니다. 도구에 없는 일(여러 파일 합치기, 통계 계산 등)은 에이전트가 "도구에 없는 기능이라 파이썬으로 직접 처리합니다"라고 알리고 진행하는 것이 정상입니다. 이때도 원본 파일은 고치지 않고 결과를 새 파일로 저장합니다. 도구에 있는 일은 먼저 도구로 하고, 도구가 안내대로 해도 또 실패하면 "도구로 처리하지 못해 파이썬으로 직접 처리합니다"라고 알리고 파이썬으로 이어 갑니다. 인쇄·회의 요청처럼 도구가 하지 않는 일은 파이썬으로도 하지 않습니다.

에이전트가 따르는 지침과 스킬 파일은 어디에 있나요?

에이전트에게 "지침 어디 있어?", "스킬 경로 알려줘"라고 물어보면 파일 위치를 알려 줍니다.
