## 시험 A: SKILL.md 순서 1~5단계를 그대로 실행

| 단계 | 명령 | 결과 | 기대 | 판정 |
|---|---|---|---|---|
| 1 | `excel.py read --target 옛 판 --save` | VERIFIED, BOM!A1:G45 (45행) | CSV 저장, range·sheet | O |
| 1 | `excel.py read --target 새 판 --save` | VERIFIED, BOM!A1:G44 (44행) | 같음 | O |
| 2 | `excel.py duplicates --columns 품번` (옛 판) | VERIFIED, 0건 (A3:G45, 42행 비교: 제목 아래 머리글 찾음) | 중복 없음 | O |
| 2 | 같은 명령 (새 판) | VERIFIED, 0건 (A3:G44, 41행) | 중복 없음 | O |
| 3 | `compare.py` | VERIFIED, `추가 2, 삭제 3, 변경 6개 부품(6칸)` | 같음 | O |
| 3 | `make_bom_samples.py --check` | `[OK] 정답과 같습니다` (정답 11건, 결과 11건) | OK | O |
| 5 | `excel.py write` 결과 표 | VERIFIED, Sheet1!A1:G12 | 머리글 + 11줄 | O |
| 5 | `excel.py style --bg yellow` | VERIFIED, 6곳 | E6, D11, E14, C17, E28, D42 | O |
| 5 | `excel.py style --bg lightgreen` | VERIFIED, 2곳 | B43, B44 | O |
| 5 | `excel.py comment --action add` | VERIFIED, 메모 6개 | 노란 칸마다 메모 | O |

COM으로 다시 읽음 (도구와 별개로):
- 새 판 칠한 칸: 노랑(#FFFF00) E6, D11, E14, C17, E28, D42 / 연두(#90EE90) B43, B44. 그 밖에 칠한 칸 없음.
- 메모 6개가 노란 칸과 같은 자리. 예: E6 `[BOM 비교] 수량: 4 -> 9 (옛 판 6행)`, D42 `[BOM 비교] 규격: EPDM 50A -> NBR 50A (옛 판 45행)`.
- 옛 판: 칠한 칸 0, 메모 0 (바뀌지 않음).
- 결과 표 12행 (머리글 + 변경 6, 추가 2, 삭제 3). 함정 7가지는 결과에 없음.
- UNVERIFIED 0건.

눈에 띈 점 (시험 판정에는 영향 없음):
- 결과 표의 추가 품번 `102`가 숫자 칸으로 들어감 (원본 새 판에서는 글 `'102'`). 비교 CSV를 `write --file`로 쓸 때 앞자리 0이 없는
  숫자 글은 숫자로 바뀌고, `0102`·`0207`만 글로 지켜짐. 보이는 값은 같음 (오른쪽 정렬, 숫자 칸).

## 시험 A (계층 샘플, bom-compare 0.2)
샘플을 계층 BOM으로 바꾼 뒤 다시 함 (사용자 요청: Level·Part Number, 중간 조립체 10개 이상, 조립체당 부품 5개 이상, 부품이 여러 조립체에 반복).
비교 기준은 사용자 결정에 따라 상위 조립체 + Part Number. 명령과 JSON: `시험A_계층_명령과_JSON.txt`, COM: `시험A_계층_COM_다시읽기.txt`.

| 단계 | 결과 | 기대 | 판정 |
|---|---|---|---|
| 1 read --save (두 판) | VERIFIED, BOM!A1:G80 | CSV 저장 | O |
| 2 compare.py | VERIFIED, `추가 4, 삭제 4, 변경 7자리(7칸)` | 같음 | O |
| 2 --check | `[OK] 정답과 같습니다` (15건) | OK | O |
| 4 write 결과 표 | VERIFIED, A1:H16 | 머리글 + 15줄 | O |
| 4 style 노랑 / 연두 | VERIFIED, 7곳 / 4곳 | D16, E21, C25, E31, E47, D58, C70 / B30, B42, B55, B80 | O (COM 확인) |
| 4 comment add | VERIFIED, 메모 7개 | 노란 칸마다, 예: E21 `[BOM 비교] Qty: 4 -> 6 (SA-03 아래, 옛 판 21행)` | O (COM 확인) |
| 옛 판 | 칠한 칸 0, 메모 0 | 바뀌지 않음 | O |
| 중복 판 (pytest·Office 없이) | `STOP_RETRY:` SA-03 아래 P-0016: 엑셀 19, 20행 | 멈춤 | O |

여러 조립체에 반복되는 부품(예: P-0001은 SA-02·03·06·08·12의 5곳)은 중복으로 멈추지 않고, SA-03의 P-0001 Qty만 변경으로 나옴. 추가 품번 `102`는 이번에도 숫자 칸 (그대로 두기로 함, CHANGELOG 남은 할 일).
